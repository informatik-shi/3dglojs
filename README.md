## Запуск

```sh
npm ci
npm run build
```

Откройте `index.html` в браузере. Готовый `dist/main.js` сохранён в репозитории.
Для пересборки при изменениях: `npm run watch`.

## Таймер

Код находится в `src/index.js`. Дата окончания акции задаётся в `deadline`
(сейчас 31 декабря 2026, 23:59:59 по Москве).
Часы показывают всё оставшееся время, поэтому могут превышать 23.
`setInterval` создаётся один раз и вызывает `updateClock` каждые 1000 мс.
Первое обновление происходит сразу. После окончания показывается `00:00:00`,
а интервал останавливается. Однозначные значения дополняются нулём.

## Дополнительное задание

Откройте `date-time/index.html`. Отдельный `script.js` показывает приветствие,
день недели, время в 12-часовом формате с AM/PM и дни до следующего Нового года.
Время берётся из часового пояса браузера, данные обновляются каждую секунду.
Ночь: 00–05, утро: 06–11, день: 12–17, вечер: 18–23.

Для проверки завершённой акции задайте в `deadline` прошедшую дату и пересоберите.
Для проверки частоты можно временно добавить `console.log` в `updateClock`:
после первого обновления вывод будет один раз в секунду до конца акции.
