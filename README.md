# 3D Glo — задание 20

## Ветка tabs — вкладки услуг и делегирование меню

В разделе «Наши услуги» три вкладки переключают соответствующие блоки.
При загрузке виден только первый блок. Вкладки доступны мышью и клавишами
стрелок, Home и End. Кнопки связаны с содержимым атрибутами ARIA.

В `src/menu.js` один обработчик кликов на документе управляет бургером,
крестиком, ссылками меню и закрытием по клику вне меню. Второй обработчик
закрывает меню по Escape. Оба используют функцию `toggleMenu()`.

## Ветка regexpr — ограничение символов

Ветка создана от обычного задания `lesson19`. В `src/regexpr.js` обработчики
`input` очищают неподходящие символы при вводе и вставке текста:

- Три текстовых поля калькулятора: только цифры. `select` не обрабатывается.
- Имя и сообщение во всех трёх формах: кириллица, пробел и дефис.
- E-mail: латинские буквы, цифры и `@ - _ . ! ~ * '`.
- Телефон: цифры, круглые скобки и дефис.

Буква `Ё/ё` считается кириллицей. Поля сохраняют положение курсора после
удаления недопустимых символов; после ввода через IME очистка происходит
по завершении композиции. Нативная проверка формата `type=email` сохраняется.

## Ветка lesson19 — меню и модальное окно

Продолжение предыдущего задания. Архив `l21-materialy-dlya-uroka.zip` изучен:
он содержит пример разметки со скроллом и кнопками, а `script.js` пустой.
Меню и окно заявки реализованы на существующем макете 3D Glo.

- `src/menu.js`: открытие меню, закрытие по крестику, ссылке, клику снаружи и Escape.
- `src/modal.js`: открытие окна кнопками заявки в разделе услуг; закрытие
  по крестику, фону и Escape. Клик внутри формы не закрывает окно.
- Появление окна длится 400 мс: `requestAnimationFrame` меняет прозрачность
  и смещение через JS. CSS-анимации и сторонние библиотеки не используются.
- При ширине окна браузера менее 768 px анимации нет. При сужении окна
  во время анимации она сразу завершается.
- При закрытии кадры отменяются, прокрутка восстанавливается, фокус возвращается
  на кнопку. Предыдущее задание с таймером и страница `date-time` сохранены.

Проверка вручную: открыть меню и перейти по ссылке; открыть заявку, кликнуть
внутри формы, закрыть по фону, крестику и Escape; быстро закрыть и открыть окно.
Сравнить появление при ширинах 767 и 768 px. Проверить консоль браузера.

Макет из l20-maket.zip, сборка из https://github.com/informatik-shi/webpack_starter_template
(коммит 7471bc9576cc80c3599909892434cd4edb153d12).

## Таймер

Код находится в `src/index.js`. Дата окончания акции задаётся в `deadline`
(сейчас 31 декабря 2026, 23:59:59 по Москве).
Часы показывают всё оставшееся время, поэтому могут превышать 23.
`setInterval` создаётся один раз и вызывает `updateClock` каждые 1000 мс.
Первое обновление происходит сразу. После окончания показывается `00:00:00`,
а интервал останавливается. Однозначные значения дополняются нулём.

## Дополнительное задание

Откройте `date-time/index.html`. Отдельный `script.js` показывает приветствие,
день недели, время в 12-часовом формате с AM/PM и дни до следующего Нового года.
Время берётся из часового пояса браузера, данные обновляются каждую секунду.
Ночь: 00–05, утро: 06–11, день: 12–17, вечер: 18–23.

Для проверки завершённой акции задайте в `deadline` прошедшую дату и пересоберите.
Для проверки частоты можно временно добавить `console.log` в `updateClock`:
после первого обновления вывод будет один раз в секунду до конца акции.
